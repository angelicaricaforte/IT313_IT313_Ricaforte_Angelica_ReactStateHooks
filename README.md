# IT313_IT313_Ricaforte_Angelica_ReactStateHooks
# Lab Timer & Practice Tracker

## Problem
This project helps students track solved practice
problems and monitor their laboratory study time.

## Approach
- useState manages the solved count and timer status.
- useEffect runs and cleans up the stopwatch interval.
- Conditional rendering displays messages and timer status.
- Lifting state up keeps child components synchronized.
- useStopwatch is a custom hook for timer logic.

## How to Run
1. Install Node.js and Expo prerequisites.
2. Create or open the Expo project.
3. Install the required project dependencies.
4. Start the Expo development server.
5. Open the project using Expo Go.
